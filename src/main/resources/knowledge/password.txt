Password Troubleshooting

1. If you cannot log in, check that Caps Lock is not enabled and enter the password carefully.

2. Make sure you are using the correct company username or email address.

3. If you forgot your password, use the company's password reset process.

4. Follow the password reset instructions and complete any required identity verification.

5. If your account is locked after multiple unsuccessful login attempts, wait for the required lockout period or contact IT support.

6. Do not share your password with other people.

7. Do not store your password in plain text or share it through email or chat.

8. If a password reset email is not received, check the spam or junk folder.

9. If the new password is not accepted, check whether it meets the company's password requirements.

10. If you can log in to some applications but not others, the issue may be related to application-specific authentication.

11. If the login problem continues after basic troubleshooting, create an IT service request with the application name and error message.

Common Password Issues:
- Forgot password
- Password reset required
- Account locked
- Login failed
- Password not accepted
- Password reset email not received
